# Majin-Gym

Applicazione mobile per allenamenti, schede, timer di recupero, diario, storico e profilo fisico.

## Avvio

```bash
npm install
npm run dev
```

## Funzioni

- profilo e dati fisici modificabili;
- BMI preciso calcolato come peso in kg diviso altezza in metri al quadrato;
- scheda lunedì/push basata sui dati forniti;
- timer recupero, registrazione serie e storico locale;
- sfondo personalizzabile con caricamento immagine;
- interfaccia mobile ispirata agli screen forniti.
